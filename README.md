# BoliviaExperience — Documentación del Proyecto

**Proyecto:** BoliviaExperience
**Slogan:** *"Toda Santa Cruz en la palma de tu mano."*
**Versión:** 1.0
**Fecha:** 2026-06-26

---

## Descripción

BoliviaExperience centraliza toda la experiencia turística de Santa Cruz de la Sierra en un único ecosistema móvil multiplataforma (Android e iOS), respaldado por un panel administrativo web y un panel para empresas.
