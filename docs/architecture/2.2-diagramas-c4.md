### Actores del Sistema

| Actor | Tipo | Interacción Principal |
|-------|------|----------------------|
| Turistas | Primario | App móvil: busca lugares, guarda favoritos, escribe opiniones |
| Negocios | Secundario | Panel web: gestiona perfil, promociones, responde opiniones |
| Admin BoliviaExperience | Interno | Panel web: gestiona contenido, usuarios, aprueba opiniones |
| Gobierno Municipal | Externo | Recibe datos turísticos anonimizados |

### Sistemas Externos

| Sistema | Propósito | Integración |
|---------|-----------|-------------|
| Google Maps API | Mapas, geocoding, directions | REST API |
| Firebase | Autenticación, almacenamiento | SDK |
| OpenWeatherMap | Datos climáticos | REST API |
| Google Play Store | Distribución Android | Deploy |
| Apple App Store | Distribución iOS | Deploy |
