# 3.3 Dark Mode y Light Mode

**Version**: 1.0  
**Date**: 2026-06-26  
**Status**: Aprobado

## 1. Visión General

BoliviaExperience soporta **Dark Mode** y **Light Mode** para ofrecer la mejor experiencia según las condiciones de uso:

- **Light Mode**: Uso diurno, exteriores, alta luminosidad
- **Dark Mode**: Uso nocturno, baja luminosidad, ahorro de batería en OLED

### 1.1 Decisiones Clave

| Decisión | Valor | Justificación |
|----------|-------|---------------|
| **Detección automática** | Sistema (default) | Respeta preferencias del dispositivo |
| **Toggle manual** | Disponible en Settings | Control total del usuario |
| **Transición** | Suave (300ms) | Sin parpadeos ni molestias |
| **Contraste WCAG** | AA (4.5:1) | Accesibilidad mínima |
| **Batería OLED** | Optimizado | Dark mode usa #000000 puro |

### 4.3 Provider de Tema

```dart
// lib/config/theme/theme_provider.dart
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

class ThemeProvider extends ChangeNotifier {
  ThemeMode _themeMode = ThemeMode.system;
  SharedPreferences? _prefs;
  
  ThemeMode get themeMode => _themeMode;
  
  ThemeProvider() {
    _loadTheme();
  }
  
  Future<void> _loadTheme() async {
    _prefs = await SharedPreferences.getInstance();
    final themeIndex = _prefs?.getInt('themeMode') ?? 0;
    _themeMode = ThemeMode.values[themeIndex];
    notifyListeners();
  }
  
  Future<void> setThemeMode(ThemeMode mode) async {
    _themeMode = mode;
    await _prefs?.setInt('themeMode', mode.index);
    notifyListeners();
  }
  
  bool get isDarkMode {
    if (_themeMode == ThemeMode.system) {
      return WidgetsBinding.instance.window.platformBrightness == Brightness.dark;
    }
    return _themeMode == ThemeMode.dark;
  }
}
```

### 5.2 Theme Toggle Component

```tsx
// src/components/ThemeToggle.tsx
import React, { useEffect, useState } from 'react';

type Theme = 'light' | 'dark' | 'system';

export const ThemeToggle: React.FC = () => {
  const [theme, setTheme] = useState<Theme>('system');
  
  useEffect(() => {
    const savedTheme = localStorage.getItem('theme') as Theme || 'system';
    setTheme(savedTheme);
    applyTheme(savedTheme);
  }, []);
  
  const applyTheme = (newTheme: Theme) => {
    if (newTheme === 'system') {
      const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
      document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
    } else {
      document.documentElement.setAttribute('data-theme', newTheme);
    }
  };
  
  const handleThemeChange = (newTheme: Theme) => {
    setTheme(newTheme);
    localStorage.setItem('theme', newTheme);
    applyTheme(newTheme);
  };
  
  return (
    <div className="theme-toggle">
      <button
        className={theme === 'light' ? 'active' : ''}
        onClick={() => handleThemeChange('light')}
        aria-label="Modo claro"
      >
        ☀️
      </button>
      <button
        className={theme === 'dark' ? 'active' : ''}
        onClick={() => handleThemeChange('dark')}
        aria-label="Modo oscuro"
      >
        🌙
      </button>
      <button
        className={theme === 'system' ? 'active' : ''}
        onClick={() => handleThemeChange('system')}
        aria-label="Automático"
      >
        💻
      </button>
    </div>
  );
};
```

### 7.2 Flutter Transición

```dart
// Transición animada al cambiar tema
class ThemeTransition extends StatefulWidget {
  final Widget child;
  final ThemeMode themeMode;
  
  const ThemeTransition({
    required this.child,
    required this.themeMode,
  });
  
  @override
  _ThemeTransitionState createState() => _ThemeTransitionState();
}

class _ThemeTransitionState extends State<ThemeTransition>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _animation;
  
  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: Duration(milliseconds: 300),
      vsync: this,
    );
    _animation = CurvedAnimation(
      parent: _controller,
      curve: Curves.easeInOut,
    );
    _controller.forward();
  }
  
  @override
  Widget build(BuildContext context) {
    return FadeTransition(
      opacity: _animation,
      child: widget.child,
    );
  }
  
  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
}
```

### 8.1 Requisitos de Contraste

| Elemento | Contraste mínimo | Ejemplo |
|----------|------------------|---------|
| Texto normal | 4.5:1 | Texto primario |
| Texto grande | 3:1 | Títulos |
| Iconos | 3:1 | Iconos interactivos |
| Bordes | 3:1 | Inputs, cards |
| Estado focus | 3:1 | Anillo de foco |

### 8.2 Respetar Preferencias del Sistema

```dart
// Detectar preferencia del sistema
class ThemeDetector {
  static Brightness getSystemBrightness() {
    return WidgetsBinding.instance.window.platformBrightness;
  }
  
  static bool get isDarkMode {
    return getSystemBrightness() == Brightness.dark;
  }
}
```

### 8.3 Animaciones Reducidas

```dart
// Respetar prefers-reduced-motion
class AnimationHelper {
  static Duration get transitionDuration {
    final mediaQuery = MediaQueryData(
      platformBrightness: WidgetsBinding.instance.window.platformBrightness,
    );
    
    // Si el usuario prefiere animaciones reducidas
    if (mediaQuery.accessibleNavigation) {
      return Duration.zero;
    }
    
    return Duration(milliseconds: 300);
  }
}
```
