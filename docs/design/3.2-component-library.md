# 3.2 Component Library — Atomic Design

**Version**: 1.0  
**Date**: 2026-06-26  
**Status**: Aprobado  

---

## 1. Visión General

La biblioteca de componentes sigue el patrón **Atomic Design** de Brad Frost, organizando los componentes en 5 niveles jerárquicos:

```
Atoms → Molecules → Organisms → Templates → Pages
```

Cada componente está documentado con:
- Propiedades (props)
- Variantes disponibles
- Estados (default, hover, active, disabled, loading)
- Uso en el contexto de BoliviaExperience
- Implementación en Flutter

---

## 2. Átomos (Atoms)

Los átomos son los elementos UI más pequeños e indivisibles.

### 2.1 Botones

#### 2.1.1 Button

| Propiedad | Tipo | Default | Descripción |
|-----------|------|---------|-------------|
| `variant` | Enum | `filled` | filled, outlined, text, tonal, elevated |
| `size` | Enum | `md` | sm, md, lg, xl |
| `color` | Enum | `primary` | primary, secondary, success, error, warning |
| `icon` | IconData? | null | Icono izquierdo |
| `iconRight` | IconData? | null | Icono derecho |
| `isLoading` | bool | false | Muestra loading spinner |
| `isFullWidth` | bool | false | Ancho completo |
| `onPressed` | VoidCallback? | null | Callback de presión |

**Variantes:**
```
┌─────────────────────────────────────────────────┐
│  FILLED          │  OUTLINED       │  TEXT       │
│  ┌───────────┐   │  ┌───────────┐  │  Explorar  │
│  │ Explorar  │   │  │ Explorar  │  │            │
│  └───────────┘   │  └───────────┘  │            │
│  bg: primary     │  border: primary│  bg: none   │
│  text: white     │  text: primary  │  text: primary│
├─────────────────────────────────────────────────┤
│  TONAL           │  ELEVATED       │             │
│  ┌───────────┐   │  ┌───────────┐  │             │
│  │ Explorar  │   │  │ Explorar  │  │             │
│  └───────────┘   │  └───────────┘  │             │
│  bg: primary-100 │  bg: primary    │             │
│  text: primary   │  shadow: elevation-2         │
└─────────────────────────────────────────────────┘
```

**Estados:**
- `default`: Color normal
- `hover`: Oscurece 8% (web), sin cambio (móvil)
- `pressed`: Oscurece 12% (web), scale 0.98 (móvil)
- `disabled`: Opacidad 38%, sin interacción
- `loading`: Spinner en lugar de texto, deshabilitado

**Estructura Flutter:**
```dart
class AppButton extends StatelessWidget {
  final ButtonVariant variant;
  final ButtonSize size;
  final ButtonColor color;
  final IconData? icon;
  final IconData? iconRight;
  final bool isLoading;
  final bool isFullWidth;
  final VoidCallback? onPressed;
  final String label;
  
  // Constructor...
}
```

**Estructura visual:**
```
┌──────────────────────────────────────┐
│  ┌────────────────────────────────┐  │
│  │         [Imagen Lugar]         │  │
│  │                    ❤️ (badge)  │  │
│  └────────────────────────────────┘  │
│  📍 Santa Cruz de la Sierra         │
│  Lugar名称                           │
│  ⭐ 4.5 (128 reseñas)              │
│  🏷️ Gastronomía · $                  │
│  ─────────────────────────────────  │
│  🕐 Abierto ahora · 1.2 km         │
│  [Ver más] [Compartir]              │
└──────────────────────────────────────┘
```

**Implementación Flutter:**
```dart
class PlaceCard extends StatelessWidget {
  final Place place;
  final bool isFavorite;
  final VoidCallback? onTap;
  final VoidCallback? onFavorite;
  final VoidCallback? onShare;
  final PlaceCardVariant variant;
  
  const PlaceCard({
    required this.place,
    this.isFavorite = false,
    this.onTap,
    this.onFavorite,
    this.onShare,
    this.variant = PlaceCardVariant.standard,
  });
  
  @override
  Widget build(BuildContext context) {
    return Card(
      elevation: 1,
      clipBehavior: Clip.antiAlias,
      child: InkWell(
        onTap: onTap,
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            _buildImage(),
            _buildContent(),
          ],
        ),
      ),
    );
  }
}
```

## 8. Accesibilidad

### 8.1 Requisitos de Accesibilidad

| Requisito | Implementación |
|-----------|----------------|
| **Touch targets** | Mínimo 48x48px para todos los interactivos |
| **Contraste texto** | Mínimo 4.5:1 para texto normal, 3:1 para texto grande |
| **Labels** | Todos los inputs tienen labels (visuales o semánticos) |
| **Screen readers** | Semantic labels para todos los iconos interactivos |
| **Navegación teclado** | Tab order lógico, focus visible |
| **Animaciones** | Respeta `prefers-reduced-motion` |

### 8.2 Implementación Flutter

```dart
// Ejemplo de botón accesible
Semantics(
  button: true,
  enabled: true,
  label: 'Agregar a favoritos',
  child: IconButton(
    icon: Icon(
      isFavorite ? Icons.favorite : Icons.favorite_border,
      color: isFavorite ? Colors.red : null,
    ),
    onPressed: onToggleFavorite,
  ),
)
```
