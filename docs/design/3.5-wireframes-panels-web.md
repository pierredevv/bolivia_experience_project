# 3.5 Wireframes Panels Web — Admin y Empresa

**Version**: 1.0  
**Date**: 2026-06-26  
**Status**: Aprobado  

---

## 1. Visión General

Los paneles web de BoliviaExperience están diseñados para:

- **Panel Admin**: Gestión completa de la plataforma (lugares, usuarios, reportes, analytics)
- **Panel Empresa**: Gestión del perfil del negocio (mi lugar, reseñas, promociones)

### 1.1 Stack Tecnológico

| Capa | Tecnología |
|------|-----------|
| Framework | React 18 |
| Build | Vite |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Components | Radix UI |
| State | React Query |
| Forms | React Hook Form |
| Charts | Recharts |
| Maps | Google Maps React |

### 1.2 Breakpoints

| Breakpoint | Ancho | Comportamiento |
|------------|-------|----------------|
| Mobile | < 768px | Sidebar colapsada |
| Tablet | 768px - 1024px | Sidebar colapsada |
| Desktop | > 1024px | Sidebar expandida |
| Large | > 1440px | Contenido expandido |
