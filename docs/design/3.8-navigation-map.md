## 2. Rutas Nombradas — Flutter

### 2.1 Definicion de Rutas

```dart
// lib/config/routes/app_routes.dart
abstract class AppRoutes {
  // Auth
  static const splash = '/splash';

  // Main (Bottom Nav)
  static const home = '/home';

  static const favorites = '/favorites';
  static const profile = '/profile';
  
  // Places
  static const placeDetail = '/places/:id';
  static const placeCreateReview = '/places/:id/reviews/create';
  static const placeReviews = '/places/:id/reviews';
  
  // Categories
  static const categories = '/categories';
  static const categoryDetail = '/categories/:id';
  
  // Events
  static const events = '/events';
  static const eventDetail = '/events/:id';

  static const promotionDetail = '/promotions/:id';

  static const editProfile = '/profile/edit';
  static const myReviews = '/profile/reviews';

  static const about = '/about';
```

```dart
// Ejemplo de navegacion
```

## 3. Bottom Navigation Structure

### 3.1 Items del Bottom Nav

```
Posicion 0: Inicio      -> /home        -> Icono: home
Posicion 1: Mapa        -> /map         -> Icono: map
Posicion 2: Explorar    -> /explore     -> Icono: search
Posicion 3: Favoritos   -> /favorites   -> Icono: favorite
Posicion 4: Perfil      -> /profile     -> Icono: person
```

### 3.2 Comportamiento

- **Fixed bottom nav**: Siempre visible en Home, Map, Explore, Favorites, Profile
- **Hidden en**: Detalle Lugar, Crear Resena, Configuracion, pantallas full-screen
- **Badge en Perfil**: Indicador de notificaciones nuevas
- **Badge en Favoritos**: Conteo de favoritos nuevos (opcional)

## 6. Deep Linking

### 6.1 URLs Soportadas

| URL | Destino | Plataforma |
|-----|---------|------------|
| `boliviaexperience://places/:id` | Detalle Lugar | App |
| `boliviaexperience://events/:id` | Detalle Evento | App |
| `boliviaexperience://promotions/:id` | Detalle Promocion | App |
| `https://boliviaexperience.com/places/:id` | Detalle Lugar | Web -> App |
| `https://boliviaexperience.com/events/:id` | Detalle Evento | Web -> App |

### 6.2 Implementacion Flutter

```dart
// lib/config/deep_links/deep_link_handler.dart
class DeepLinkHandler {
  static void handleLink(String link) {
    final uri = Uri.parse(link);
    
    if (uri.host == 'boliviaexperience.com' || 
        uri.scheme == 'boliviaexperience') {
      
      final pathSegments = uri.pathSegments;
      
      if (pathSegments.isNotEmpty) {
        switch (pathSegments[0]) {
          case 'places':
            if (pathSegments.length > 1) {
              // Navigate to place detail
            }
            break;
          case 'events':
            if (pathSegments.length > 1) {
              // Navigate to event detail
            }
            break;
          case 'promotions':
            if (pathSegments.length > 1) {
              // Navigate to promotion detail
            }
            break;
        }
      }
    }
  }
}
```

## 7. Estrategia de Navegacion

### 7.1 Principios

| Principio | Descripcion |
|-----------|-------------|
| **Flat hierarchy** | Maximo 3 niveles de profundidad |
| **Consistent back** | Siempre hay forma de volver atras |
| **Bottom nav visible** | En pantallas principales |
| **Clear affordance** | Los botones deben ser evidentes |
| **Minimal taps** | Máximo 3 taps para llegar a cualquier destino |

### 7.2 Jerarquia de Pantallas

```
Nivel 0: Splash, Onboarding, Login
Nivel 1: Home, Map, Explore, Favorites, Profile (Bottom Nav)
Nivel 2: Detalle Lugar, Lista Eventos, Lista Promociones, Settings
Nivel 3: Crear Resena, Detalle Evento, Detalle Promocion, Edit Profile
```

### 7.3 Transiciones

| Transicion | Tipo | Duracion |
|------------|------|----------|
| Bottom Nav | Fade | 200ms |
| Push (adelante) | Slide from right | 300ms |
| Pop (atras) | Slide from left | 300ms |
| Modal (bottom sheet) | Slide from bottom | 300ms |
| Dialog | Scale + Fade | 200ms |

## 8. Estado de Navegacion

### 8.1 Persistencia

| Elemento | Persistencia | Metodo |
|----------|--------------|--------|
| Sesion usuario | Token JWT | Secure Storage |
| Favoritos | Cache local | Hive/SQLite |
| Historial busqueda | Cache local | Hive |
| Preferencias | Persistentes | SharedPreferences |
| Tema (dark/light) | Persistente | SharedPreferences |
| Idioma | Persistente | SharedPreferences |

### 8.2 Estado por Pantalla

| Pantalla | Estado requerido | Provider |
|----------|------------------|----------|
| Home | Lugares cercanos, clima, eventos | PlacesProvider, WeatherProvider |
| Mapa | Ubicacion, markers, filtros | MapProvider |
| Explorar | Resultados busqueda, filtros | SearchProvider |
| Favoritos | Lista favoritos | FavoritesProvider |
| Perfil | Datos usuario, resenas | AuthProvider, ReviewsProvider |
| Detalle Lugar | Lugar, resenas, estado favorito | PlaceDetailProvider |
