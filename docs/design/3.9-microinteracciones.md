# 3.9 Microinteracciones y Animaciones

**Version**: 1.0
**Date**: 2026-06-26
**Status**: Aprobado

## 1. Visión General

Las microinteracciones son animaciones pequeñas que proporcionan feedback visual al usuario. En BoliviaExperience, estas animaciones deben ser:

- **Rapidas**: 100-300ms maximo
- **Significativas**: Cada animacion tiene un proposito
- **Consistentes**: Mismos tiempos y easing en toda la app
- **No intrusivas**: No interrumpir el flujo del usuario
- **Accesibles**: Respetar prefers-reduced-motion

## 2. Timing y Easing

### 2.1 Duraciones

| Token | Duracion | Uso |
|-------|----------|-----|
| `instant` | 0-50ms | Cambios de color, opacidad |
| `fast` | 100-150ms | Press states, hover |
| `normal` | 200-300ms | Transiciones estandar |
| `slow` | 400-500ms | Animaciones complejas |

### 2.2 Easing Curves

| Curva | Bezier | Uso |
|-------|--------|-----|
| `ease-in` | (0.4, 0, 1, 1) | Elementos saliendo de pantalla |
| `ease-out` | (0, 0, 0.2, 1) | Elementos entrando a pantalla |
| `ease-in-out` | (0.4, 0, 0.2, 1) | Cambios de estado |
| `spring` | (0.175, 0.885, 0.32, 1.275) | Animaciones con rebote |
| `decelerate` | (0, 0, 0.2, 1) | Desaceleracion suave |

## 3. Animaciones por Componente

### 3.1 Botones

| Interaccion | Animacion | Duracion | Detalle |
|-------------|-----------|----------|---------|
| Press | Scale down | 100ms | Scale a 0.95 |
| Release | Scale up + bounce | 200ms | Scale a 1.0 con spring |
| Loading | Spinner rotation | 1000ms loop | Rotacion continua |
| Success | Check animation | 300ms | Icono de check aparece |

**Flutter Implementation:**
```dart
class AnimatedButton extends StatefulWidget {
  @override
  _AnimatedButtonState createState() => _AnimatedButtonState();
}

class _AnimatedButtonState extends State<AnimatedButton>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _scaleAnimation;
  
  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: Duration(milliseconds: 200),
      vsync: this,
    );
    _scaleAnimation = Tween<double>(begin: 1.0, end: 0.95)
        .animate(CurvedAnimation(
      parent: _controller,
      curve: Curves.easeInOut,
    ));
  }
  
  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTapDown: (_) => _controller.forward(),
      onTapUp: (_) => _controller.reverse(),
      child: AnimatedBuilder(
        animation: _scaleAnimation,
        builder: (context, child) {
          return Transform.scale(
            scale: _scaleAnimation.value,
            child: child,
          );
        },
        child: YourButtonContent(),
      ),
    );
  }
}
```

### 3.2 Favoritos (Corazon)

| Interaccion | Animacion | Duracion | Detalle |
|-------------|-----------|----------|---------|
| Tap para agregar | Pop + fill | 300ms | Corazon se llena con bounce |
| Tap para quitar | Fade out | 200ms | Corazon se desvanece |
| En lista | Scale + color | 250ms | Scale de 1.0 a 1.3 y vuelta |

**Flutter Implementation:**
```dart
class AnimatedFavorite extends StatefulWidget {
  final bool isFavorite;
  final VoidCallback onTap;
  
  @override
  _AnimatedFavoriteState createState() => _AnimatedFavoriteState();
}

class _AnimatedFavoriteState extends State<AnimatedFavorite>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _scaleAnimation;
  late Animation<Color?> _colorAnimation;
  
  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: Duration(milliseconds: 300),
      vsync: this,
    );
    _scaleAnimation = TweenSequence<double>([
      TweenSequenceItem(tween: Tween(begin: 1.0, end: 1.3), weight: 50),
      TweenSequenceItem(tween: Tween(begin: 1.3, end: 1.0), weight: 50),
    ]).animate(CurvedAnimation(
      parent: _controller,
      curve: Curves.easeInOut,
    ));
    _colorAnimation = ColorTween(
      begin: Colors.grey,
      end: Colors.red,
    ).animate(_controller);
  }
  
  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () {
        widget.onTap();
        if (!widget.isFavorite) {
          _controller.forward(from: 0.0);
        } else {
          _controller.reverse();
        }
      },
      child: AnimatedBuilder(
        animation: _controller,
        builder: (context, child) {
          return Transform.scale(
            scale: _scaleAnimation.value,
            child: Icon(
              widget.isFavorite ? Icons.favorite : Icons.favorite_border,
              color: _colorAnimation.value,
            ),
          );
        },
      ),
    );
  }
}
```

**Shimmer Implementation:**
```dart
class ShimmerEffect extends StatefulWidget {
  @override
  _ShimmerEffectState createState() => _ShimmerEffectState();
}

class _ShimmerEffectState extends State<ShimmerEffect>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  
  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: Duration(milliseconds: 1500),
      vsync: this,
    )..repeat();
  }
  
  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return Container(
          decoration: BoxDecoration(
            gradient: LinearGradient(
              begin: Alignment(-1.0 + 2.0 * _controller.value, 0),
              end: Alignment(-1.0 + 2.0 * _controller.value + 1, 0),
              colors: [
                Colors.grey[300]!,
                Colors.grey[100]!,
                Colors.grey[300]!,
              ],
            ),
          ),
        );
      },
    );
  }
}
```

```

```

## 5. Animaciones de Listas

### 5.1 Staggered Animation

Cuando una lista carga por primera vez, los elementos aparecen en secuencia:

```dart
class StaggeredListItem extends StatelessWidget {
  final int index;
  final Animation<double> animation;
  
  @override
  Widget build(BuildContext context) {
    final delay = index * 0.1; // 100ms por item
    final curvedAnimation = CurvedAnimation(
      parent: animation,
      curve: Interval(delay, delay + 0.5, curve: Curves.easeOut),
    );
    
    return FadeTransition(
      opacity: curvedAnimation,
      child: SlideTransition(
        position: Tween<Offset>(
          begin: Offset(0, 0.1),
          end: Offset.zero,
        ).animate(curvedAnimation),
        child: YourListItem(),
      ),
    );
  }
}
```

## 8. Accesibilidad de Animaciones

### 8.1 Respeta prefers-reduced-motion

```dart
class AccessibleAnimation {
  static Duration getTransitionDuration(BuildContext context) {
    final mediaQuery = MediaQuery.of(context);
    
    // Si el usuario prefiere animaciones reducidas
    if (mediaQuery.accessibleNavigation) {
      return Duration.zero;
    }
    
    return Duration(milliseconds: 300);
  }
  
  static Widget wrapWithAnimation({
    required BuildContext context,
    required Widget child,
    required Widget Function(Widget) animationBuilder,
  }) {
    if (MediaQuery.of(context).accessibleNavigation) {
      return child;
    }
    
    return animationBuilder(child);
  }
}
```

### 8.2 Override Global

```dart
// En main.dart
MaterialApp(
  builder: (context, child) {
    return MediaQuery(
      data: MediaQuery.of(context).copyWith(
        // Deshabilitar animaciones si el usuario lo prefiere
        disableAnimations: false, // Respeta preferencias del sistema
      ),
      child: child!,
    );
  },
)
```

## 9. Performance

### 9.1 Reglas de Performance

| Regla | Detalle |
|-------|---------|
| **Max animaciones simultaneas** | 3-4 animaciones maximo |
| **Evitar repaint en scroll** | Usar RepaintBoundary |
| **Usar AnimatedBuilder** | No rebuildar todo el widget |
| **Cachear calculos** | No recalcular en cada frame |
| **Usar Hero transitions** | Para transiciones entre pantallas |

### 9.2 Optimizaciones

```dart
// Usar RepaintBoundary para listas
ListView.builder(
  itemBuilder: (context, index) {
    return RepaintBoundary(
      child: PlaceCard(place: places[index]),
    );
  },
)

// Usar const para widgets estaticos
const Text('BoliviaExperience')

// Evitar rebuilds innecesarios con keys
ListView.builder(
  key: const PageStorageKey<String>('places-list'),
  itemBuilder: ...
)
```
