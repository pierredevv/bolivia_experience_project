# 3.1 Design Tokens — BoliviaExperience

**Version**: 1.0  
**Date**: 2026-06-26  
**Status**: Aprobado  

---

## 1. Visión General

Los Design Tokens son los elementos visuales atómicos que definen la identidad visual de BoliviaExperience. Están diseñados para:

- Reflejar la identidad boliviana (naturaleza, cultura, calidez)
- Funcionar en dispositivos gama media-baja (2-4GB RAM)
- Cumplir WCAG 2.1 AA (contraste mínimo 4.5:1)
- Soportar Dark Mode y Light Mode
- Ser implementados en Flutter (ThemeExtension) y React (CSS Variables)

### 2.7 Colores de Marca (Logo BoliviaExperience)

Los colores de marca derivan directamente del logo oficial, que representa la diversidad geográfica y cultural de Bolivia.

| Token | Valor | Uso | Origen Logo |
|-------|-------|-----|-------------|
| `brand-red` | #E53935 | Cultura, festivales, energía | Triángulo rojo (izquierda) |
| `brand-orange` | #FF9800 | Sol, calidez, oriente | Triángulo naranja (arriba) |
| `brand-yellow` | #FFC107 | Luz, alegría, diversión | Triángulo amarillo (arriba) |
| `brand-green` | #43A047 | Naturaleza, Yungas, selva (= primary-700) | Triángulo verde (centro) |
| `brand-green-dark` | #2E7D32 | Naturaleza oscura, profundidad | Sombra del verde |
| `brand-blue` | #1565C0 | Cielo, agua, tecnología (= secondary-800) | Triángulo azul (abajo) |
| `brand-blue-dark` | #0D47A1 | Profundidad, confianza | Sombra del azul |

**Reglas de Uso:**
- Los colores de marca son para **elementos decorativos** y **acentos visuales**
- Para **texto** y **elementos interactivos** usar primary/secondary del sistema
- En **gradientes**, usar combinaciones de colores de marca para evocar el logo
- **NUNCA** usar colores de marca para fondos de botones o inputs

**Gradientes de Marca:**
```
brand-gradient-sunrise: linear-gradient(135deg, #E53935, #FF9800, #FFC107)
brand-gradient-nature: linear-gradient(135deg, #2E7D32, #43A047, #66BB6A)
brand-gradient-sky: linear-gradient(135deg, #0D47A1, #1565C0, #42A5F5)
brand-gradient-full: linear-gradient(135deg, #E53935, #FF9800, #FFC107, #43A047, #1565C0)
```

## 12. Implementación

### 12.1 Flutter (ThemeExtension)

```dart
// lib/config/theme/app_tokens.dart
import 'package:flutter/material.dart';

class AppColors extends ThemeExtension<AppColors> {
  final Color primary900;
  final Color primary700;
  final Color primary500;
  final Color primary300;
  final Color primary100;
  
  // ... otros colores
  
  @override
  AppColors copyWith({...}) {
    return AppColors(
      primary900: primary900 ?? this.primary900,
      primary700: primary700 ?? this.primary700,
      // ...
    );
  }
  
  @override
  AppColors lerp(AppColors? other, double t) {
    if (other is! AppColors) return this;
    return AppColors(
      primary900: Color.lerp(primary900, other.primary900, t),
      primary700: Color.lerp(primary700, other.primary700, t),
      // ...
    );
  }
}
```
