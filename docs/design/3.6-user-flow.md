## 2. Flujo: Registro

```
Inicio -> Onboarding (3 pasos) -> Login -> "Tienes cuenta?"
                                          |          |
                                         [No]       [Si]
                                          |          |
                                     Registro    Login
                                          |          |
                                 [Google] [Form]     |
                                      |              |
                                 Google OAuth        |
                                      |              |
                                 Completar Perfil    |
                                      |              |
                                      v              v
                                   HOME (registrado)
```

**Pasos detallados:**

1. Splash Screen (2-3 seg)
2. Onboarding (3 pasos, omitible)
3. Pantalla Login
4. Si no tiene cuenta: Registro
   - Opcion Google OAuth (preferida)
   - Opcion formulario (email + password + nombre + pais)
5. Google OAuth: popup/redirect -> autorizar
6. Completar perfil: nombre, pais, idioma preferido
7. Redirigir a Home

**Metricas:**
- Tiempo promedio: menos de 2 minutos
- Tasa de conversion: mayor a 60%
- Errores: menor a 5%

## 3. Flujo: Buscar y Visitar Lugar

```
HOME -> [Buscar] -> Input busqueda -> Resultados -> Seleccionar -> Detalle Lugar
  |                                                        |
  +-> [Mapa] -> Markers -> Tap marker -> Preview -> Detalle Lugar
  |
  +-> [Explorar] -> Categorias -> Filtros -> Resultados -> Detalle Lugar
```

**Pasos detallados:**

1. Desde Home, el usuario puede:
   - Tocar barra de busqueda
   - Tocar icono de mapa
   - Tocar "Explorar"
   - Tocar una categoria
2. **Busqueda directa:**
   - Ingresar texto
   - Ver sugerencias en tiempo real
   - Seleccionar sugerencia o presionar buscar
   - Ver resultados con filtros activos
3. **Mapa:**
   - Ver markers en el mapa
   - Tocar marker para ver preview
   - Tocar "Ver mas" para detalle completo
4. **Explorar:**
   - Seleccionar categoria(s)
   - Aplicar filtros (precio, distancia, rating)
   - Ver resultados filtrados
5. **Detalle del lugar:**
   - Ver informacion completa
   - Acciones: favorito, compartir, como llegar, llamar, ver reviews

**Metricas:**
- Tiempo hasta primer resultado: menos de 3 segundos
- Tasa de seleccion de resultado: mayor a 40%
- Tasa de retorno a busqueda: menor a 30%

## 4. Flujo: Dejar Resena

```
Detalle Lugar -> [Escribir resena] -> Rating (1-5 estrellas)
                                           |
                                     Texto (opcional)
                                           |
                                     Fotos (opcional, max 5)
                                           |
                                     Fecha de visita
                                           |
                                     [Publicar]
                                           |
                                     Verificacion
                                           |
                                     Resena publicada
```

**Pasos detallados:**

1. Desde Detalle Lugar, tocar "Escribir resena"
2. Seleccionar rating (1-5 estrellas)
3. Escribir texto (opcional, max 500 caracteres)
4. Agregar fotos (opcional, max 5)
5. Seleccionar fecha de visita
6. Tocar "Publicar"
7. Snackbar de confirmacion
8. Resena aparece en la lista (puede requerir aprobacion)

**Requisitos:**
- Rating es obligatorio
- Texto es opcional pero recomendado
- Maximo 5 fotos de 5MB cada una
- Solo 1 resena por usuario por lugar

## 5. Flujo: Agregar a Favoritos

```
Detalle Lugar -> [Corazon] -> Toggle favorito -> Snackbar confirmacion
    |
    +-> Si no esta logueado -> Login prompt -> Login -> Toggle favorito
```

**Pasos detallados:**

1. Tocar icono de corazon
2. Si esta logueado: toggle inmediato
3. Si no esta logueado: prompt de login
4. Despues de login: toggle favorito
5. Snackbar: "Agregado a favoritos" / "Eliminado de favoritos"

---

## 6. Flujo: Compartir Lugar

```
Detalle Lugar -> [Compartir] -> Bottom Sheet opciones
                                    |
                    +---------------+---------------+
                    |               |               |
                WhatsApp        Copiar         Mas opciones
                    |               |               |
              Abrir WhatsApp   Link copiado   Share sheet
                                  |               |
                          Snackbar "Link    Enviar por app
                          copiado"          seleccionada
```

**Pasos detallados:**

1. Tocar icono de compartir
2. Bottom sheet con opciones:
   - WhatsApp (directo)
   - Copiar enlace
   - SMS
   - Email
   - Mas opciones (share sheet del SO)
3. Ejecutar accion seleccionada
4. Snackbar de confirmacion

## 7. Flujo: Ver y Responder Resenas

```
Detalle Lugar -> [Ver resenas] -> Lista resenas -> Filtrar/Ordenar
                                        |
                                  Seleccionar resena
                                        |
                                  Detalle resena
                                        |
                              [Like] [Responder] [Reportar]
```

**Pasos detallados:**

1. Desde Detalle Lugar, tocar "Ver resenas"
2. Ver resumen de rating (promedio, distribucion)
3. Filtrar: Todas, Recientes, Con fotos
4. Cada resena muestra: avatar, nombre, rating, texto, fotos, fecha
5. Acciones por resena: like, responder, reportar
6. El dueño del lugar puede responder resenas

## 12. Puntos de Decision Clave

### 12.1 Login vs Guest

| Feature | Guest | Logged In |
|---------|-------|-----------|
| Ver lugares | Si | Si |
| Buscar lugares | Si | Si |
| Ver mapa | Si | Si |
| Dejar resena | No | Si |
| Favoritos | No | Si |
| Compartir | Si | Si |
| Recibir notificaciones | No | Si |
| Guardar preferencias | No | Si |
