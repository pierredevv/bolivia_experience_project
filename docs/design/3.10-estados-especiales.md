# 3.10 Estados Especiales — Error, Vacio, Offline, Skeleton

**Version**: 1.0
**Date**: 2026-06-26
**Status**: Aprobado

---

## 1. Visión General

Los estados especiales son pantallas y componentes que manejan situaciones fuera del flujo normal de la aplicacion. Un buen manejo de estos estados es critico para la experiencia del usuario, especialmente en Bolivia donde la conectividad puede ser inestable.

### 1.1 Tipos de Estado

| Estado | Descripcion | Prioridad |
|--------|-------------|-----------|
| **Skeleton** | Cargando datos | Alta |
| **Empty** | Sin datos para mostrar | Alta |
| **Error** | Fallo al cargar/guardar datos | Alta |
| **Offline** | Sin conexion a internet | Alta |
| **Success** | Operacion completada | Media |
| **Loading** | Operacion en progreso | Media |

### 2.5 Componente Shimmer Reutilizable

```dart
class ShimmerContainer extends StatelessWidget {
  final double? height;
  final double? width;
  final double borderRadius;
  
  const ShimmerContainer({
    this.height,
    this.width,
    this.borderRadius = 8.0,
  });
  
  @override
  Widget build(BuildContext context) {
    return Container(
      height: height,
      width: width,
      decoration: BoxDecoration(
        color: Colors.grey[300],
        borderRadius: BorderRadius.circular(borderRadius),
      ),
      child: Shimmer.fromColors(
        baseColor: Colors.grey[300]!,
        highlightColor: Colors.grey[100]!,
        child: Container(
          decoration: BoxDecoration(
            color: Colors.white,
            borderRadius: BorderRadius.circular(borderRadius),
          ),
        ),
      ),
    );
  }
}
```

### 3.6 Patron de Empty State Reutilizable

```dart
class EmptyState extends StatelessWidget {
  final IconData icon;
  final String title;
  final String message;
  final String? actionLabel;
  final VoidCallback? onAction;
  
  const EmptyState({
    required this.icon,
    required this.title,
    required this.message,
    this.actionLabel,
    this.onAction,
  });
  
  @override
  Widget build(BuildContext context) {
    return Center(
      child: Padding(
        padding: EdgeInsets.all(32),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Icon(
              icon,
              size: 80,
              color: Colors.grey[400],
            ),
            SizedBox(height: 24),
            Text(
              title,
              style: Theme.of(context).textTheme.headlineSmall,
              textAlign: TextAlign.center,
            ),
            SizedBox(height: 12),
            Text(
              message,
              style: Theme.of(context).textTheme.bodyMedium?.copyWith(
                color: Colors.grey[600],
              ),
              textAlign: TextAlign.center,
            ),
            if (actionLabel != null && onAction != null) ...[
              SizedBox(height: 24),
              ElevatedButton(
                onPressed: onAction,
                child: Text(actionLabel!),
              ),
            ],
          ],
        ),
      ),
    );
  }
}

// Uso:
EmptyState(
  icon: Icons.favorite_border,
  title: 'No tienes lugares guardados',
  message: 'Explora Santa Cruz y guarda tus lugares favoritos aqui.',
  actionLabel: 'Explorar Lugares',
  onAction: () => Navigator.pushNamed(context, '/explore'),
)
```

```dart
  }
```


### 5.2 Datos Disponibles Offline

| Dato | Disponible | Metodo de Cache |
|------|------------|-----------------|
| Lugares cercanos | Si | Hive (ultima ubicacion conocida) |
| Detalle de lugar | Si | Hive (lugares visitados) |
| Favoritos | Si | SQLite local |
| Busquedas recientes | Si | Hive |
| Perfil de usuario | Si | SharedPreferences |
| Eventos | Parcialmente | Hive (ultima semana) |
| Resenas | No | Requiere conexion |
| Mapa | Parcialmente | Tiles cacheados |

### 5.3 Estrategia de Cache

```dart
class CacheStrategy {
  // Lugares: cache por 24 horas
  static const placesTTL = Duration(hours: 24);
  
  // Detalle lugar: cache por 12 horas
  static const placeDetailTTL = Duration(hours: 12);
  
  // Eventos: cache por 6 horas
  static const eventsTTL = Duration(hours: 6);
  
  // Resenas: cache por 1 hora
  static const reviewsTTL = Duration(hours: 1);
  
  // Busquedas: cache por 30 dias
  static const searchHistoryTTL = Duration(days: 30);
  
  // Favoritos: sync inmediato cuando hay conexion
  static const favoritesTTL = Duration.zero;
}
```

### 5.4 Sincronizacion Offline-Online

```
Estado Offline:
1. Usuario realiza acciones (favorito, resena)
2. Acciones se guardan localmente
3. Se muestra indicador "pendiente de sincronizacion"

Estado Online:
1. Detectar conexion restaurada
2. Sincronizar cambios pendientes
3. Mostrar snackbar "Datos sincronizados"
4. Actualizar UI con datos del servidor
```

## 9. Implementacion Flutter

### 9.1 Connectivity Service

```dart
// lib/core/services/connectivity_service.dart
import 'package:connectivity_plus/connectivity_plus.dart';
import 'package:rxdart/rxdart.dart';

class ConnectivityService {
  final _connectivity = Connectivity();
  final _connectivityController = BehaviorSubject<ConnectivityResult>();
  
  Stream<ConnectivityResult> get connectivityStream => 
      _connectivityController.stream;
  
  bool _isConnected = false;
  bool get isConnected => _isConnected;
  
  Future<void> init() async {
    final result = await _connectivity.checkConnectivity();
    _connectivityController.add(result);
    _isConnected = result != ConnectivityResult.none;
    
    _connectivity.onConnectivityChanged.listen((result) {
      _connectivityController.add(result);
      _isConnected = result != ConnectivityResult.none;
    });
  }
  
  void dispose() {
    _connectivityController.close();
  }
}
```

### 9.2 Offline-Aware Widget

```dart
// lib/core/widgets/offline_aware_widget.dart
class OfflineAwareWidget extends StatelessWidget {
  final Widget child;
  final Widget? offlineChild;
  
  const OfflineAwareWidget({
    required this.child,
    this.offlineChild,
  });
  
  @override
  Widget build(BuildContext context) {
    return StreamBuilder<ConnectivityResult>(
      stream: connectivityService.connectivityStream,
      builder: (context, snapshot) {
        final isConnected = snapshot.data != ConnectivityResult.none;
        
        if (!isConnected && offlineChild != null) {
          return offlineChild!;
        }
        
        return child;
      },
    );
  }
}
```

### 9.3 Error Handler

```dart
// lib/core/error/error_handler.dart
class ErrorHandler {
  static String getErrorMessage(dynamic error) {
    if (error is SocketException) {
      return 'Sin conexion a internet. Verifica tu conexion.';
    }
    if (error is TimeoutException) {
      return 'La conexion tardo demasiado. Intenta de nuevo.';
    }
    if (error is HttpException) {
      return 'Error del servidor. Intenta mas tarde.';
    }
    return 'Algo salio mal. Intenta de nuevo.';
  }
  
  static String getErrorCode(dynamic error) {
    if (error is SocketException) return 'ERR_NETWORK';
    if (error is TimeoutException) return 'ERR_TIMEOUT';
    if (error is HttpException) return 'ERR_SERVER';
    return 'ERR_UNKNOWN';
  }
}
```

## 11. Mensajes de Error

### 11.1 Mensajes por Codigo de Error

| Codigo | Mensaje Usuario | Accion |
|--------|-----------------|--------|
| ERR_NETWORK | Sin conexion a internet | Reintentar, verificar wifi |
| ERR_TIMEOUT | La conexion tardo demasiado | Reintentar |
| ERR_SERVER | Error del servidor | Intentar mas tarde |
| ERR_404 | Recurso no encontrado | Volver atras |
| ERR_429 | Demasiadas solicitudes | Esperar 30 segundos |
| ERR_500 | Error interno del servidor | Reportar problema |
| ERR_AUTH | Sesion expirada | Volver a iniciar sesion |
| ERR_PERMISSION | Sin permiso | Solicitar permiso |

### 11.2 Convenciones de Mensajes

| Regla | Ejemplo |
|-------|---------|
| Hablar en first person | "No pudimos cargar" vs "Error al cargar" |
| Ser especifico | "Sin conexion a internet" vs "Error" |
| Ofrecer solucion | "Verifica tu conexion" vs "Error de red" |
| Ser amigable | "Algo salio mal" vs "ERROR FATAL" |
| Incluir codigo | "Codigo: ERR_504" para soporte |
