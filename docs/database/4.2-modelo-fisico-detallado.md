## 1. Convenciones de Nombres

| Elemento | Convención | Ejemplo |
|----------|-----------|---------|
| Tablas | snake_case, plural | `users`, `place_photos` |
| Columnas | snake_case | `rating_avg`, `created_at` |
| Primary Keys | `id` | UUID generado con `gen_random_uuid()` |
| Foreign Keys | `{tabla_singular}_id` | `user_id`, `place_id` |
| Índices | `idx_{tabla}_{columna}` | `idx_places_category` |
| Restricciones | `chk_{tabla}_{columna}` | `chk_reviews_rating` |
| Uniques | `uq_{tabla}_{columnas}` | `uq_favorites_user_place` |
| Triggers | `trg_{tabla}_{evento}` | `trg_users_updated_at` |
