## 1. Resumen del Modelo

El modelo de datos de BoliviaExperience consta de **11 entidades principales** y **3 entidades de soporte**, diseñadas para soportar:

- Gestión de usuarios y autenticación (Firebase + JWT)
- Catálogo de lugares turísticos con geolocalización (PostGIS)
- Sistema de reseñas y calificaciones
- Eventos y promociones
- Favoritos e historial de búsqueda
- Analytics y métricas

## 4. Restricciones de Integridad

### 4.1 Restricciones de Dominio

| Tabla | Columna | Restricción |
|-------|---------|-------------|
| users | role | CHECK (role IN ('admin', 'empresa', 'usuario')) |
| users | language | CHECK (language IN ('es', 'en', 'pt')) |
| reviews | rating | CHECK (rating >= 1 AND rating <= 5) |
| promotions | discount_percentage | CHECK (discount_percentage >= 0 AND discount_percentage <= 100) |
| place_hours | day_of_week | CHECK (day_of_week >= 0 AND day_of_week <= 6) |
| analytics_events | platform | CHECK (platform IN ('android', 'ios', 'web')) |

### 4.2 Restricciones de Unicidad

| Tabla | Columnas | Propósito |
|-------|----------|-----------|
| users | email | Un email por usuario |
| users | firebase_uid | Un Firebase UID por usuario |
| categories | slug | URL-friendly identifier |
| favorites | (user_id, place_id) | Un favorito por usuario por lugar |
| reviews | (user_id, place_id) | Una reseña por usuario por lugar |
| place_hours | (place_id, day_of_week) | Un horario por día por lugar |

### 4.3 Restricciones de Negocio

- **rating_avg**: Se calcula automáticamente como AVG de reviews.is_approved = true
- **rating_count**: Se calcula automáticamente como COUNT de reviews.is_approved = true
- **is_featured**: Solo admin puede marcar lugares como destacados
- **is_approved**: Reviews requieren aprobación de admin antes de ser visibles

## 5. Entidades de Auditoría

Todas las tablas principales incluyen:

| Columna | Tipo | Default | Propósito |
|---------|------|---------|-----------|
| created_at | TIMESTAMP WITH TIME ZONE | NOW() | Fecha de creación |
| updated_at | TIMESTAMP WITH TIME ZONE | NOW() | Última modificación |

**Trigger de auditoría**: Actualizar `updated_at` automáticamente en cada UPDATE.

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

-- Aplicar a todas las tablas con updated_at
CREATE TRIGGER update_users_updated_at BEFORE UPDATE ON users
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_places_updated_at BEFORE UPDATE ON places
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_reviews_updated_at BEFORE UPDATE ON reviews
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_events_updated_at BEFORE UPDATE ON events
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_promotions_updated_at BEFORE UPDATE ON promotions
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```
