## ADR-009: Presupuesto del MVP vs Alcance

**Fecha:** 2026-06-26
**Estado:** Aceptado (referencia a ADR-001)

**Contexto:**
El presupuesto original del proyecto ($20,000-30,000) es significativamente menor que el costo real estimado ($58,310 para equipo reducido).

**Opciones consideradas:**
- Opción A — Reducir alcance al presupuesto disponible
  · Ventajas: Within budget
  · Desventajas: Producto incompleto
- Opción B — Incrementar presupuesto
  · Ventajas: Producto completo
  · Desventajas: Requiere inversión adicional
- Opción C — Fasear desarrollo
  · Ventajas: MVP realista + complemento post-validación
  · Desventajas: Complejidad de gestión

**Decisión:**
Opción C — Fasear desarrollo (confirmación de ADR-001):
- **Fase 1 (MVP — $20,000-30,000):** App core + backend básico + panel admin mínimo
- **Fase 1.5 (Post-MVP — $15,000-20,000):** Panels completos + features adicionales
- **Fase 2 (Validación — $10,000-15,000):** Iteraciones basadas en feedback

**Consecuencias:**
- Positivas: MVP lanza con presupuesto realista
- Negativas: Algunas features se retrasan
- Deuda técnica: Posible refactorización

**Revisión:** Revisar después de MVP y primeros datos de uso.

## Recomendaciones Financieras

### Para el MVP ($20,000-30,000)

1. **Equipo reducido:** 4 personas full-time (Tech Lead, 2 devs, designer part-time)
2. **Infraestructura mínima:** GCP estrictamente necesario, Firebase free tier
3. **Marketing orgánico:** Contenido en redes sociales, boca a boca, partnership con hostales
4. **Cero gastos opcionales:** No invertir en features no esenciales

### Para Escalar (Post-MVP)

1. **Reinvertir primeros ingresos:** 50% en marketing, 30% en desarrollo, 20% en infra
2. **Buscar inversión seed:** Si los KPIs son positivos, buscar $50K-100K para escalar
3. **Optimizar costos:** Caché, CDN, optimización de queries
4. **Diversificar ingresos:** No depender solo de suscripciones
