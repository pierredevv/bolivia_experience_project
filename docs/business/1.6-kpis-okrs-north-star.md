## North Star Metric

### Definición

**"Lugares consultados por turista durante su estadía en Santa Cruz"**

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                         NORTH STAR METRIC — BoliviaExperience                          │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│                          ╔═══════════════════════════════════════╗                      │
│                          ║                                       ║                      │
│                          ║   Lugares consultados por turista     ║                      │
│                          ║                                       ║                      │
│                          ║            TARGET MVP: 3              ║                      │
│                          ║                                       ║                      │
│                          ╚═══════════════════════════════════════╝                      │
│                                                                                         │
│  FÓRMULA:                                                                               │
│  ─────────                                                                              │
│  North Star = Total lugares consultados (fichas vistas) / Total turistas activos        │
│                                                                                         │
│  POR QUÉ ESTA MÉTRICA:                                                                  │
│  ────────────────────                                                                   │
│  • Refleja directamente el VALOR entregado al usuario                                   │
│  • Si un turista consulta 3+ lugares, la app le está siendo útil                        │
│  • Correlaciona con retención y satisfacción                                            │
│  • Es medible y accionable                                                              │
│  • No se puede "hackear" artificialmente                                                │
│                                                                                         │
│  VALIDACIÓN:                                                                            │
│  ───────────                                                                            │
│  • Si North Star ≥ 3 → Los turistas están usando la app como herramienta útil          │
│  • Si North Star < 2 → La app no está generando suficiente valor                        │
│  • Si North Star < 1 → La app no está resolviendo el problema                          │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### Desglose del North Star Metric

| Componente | Definición | Target | Cómo influye |
|------------|-----------|--------|--------------|
| Numerador: Lugares consultados | Total de fichas de establecimientos abiertas por todos los usuarios | 1,500/mes (500 turistas × 3) | Más consultas = más valor entregado |
| Denominario: Turistas activos | Usuarios que completan onboarding y tienen ≥2 sesiones | 500/mes | Base de usuarios creciendo |
| **North Star Result** | Lugares/turista | **3.0** | Métrica final |

## ADR-008: North Star Metric — Justificación

**Fecha:** 2026-06-26
**Estado:** Aceptado

**Contexto:**
Definir una métrica principal que guíe todas las decisiones de producto y negocio.

**Opciones consideradas:**
- Opción A — Descargas totales
  · Ventajas: Fácil de medir, crecimiento visible
  · Desventajas: No refleja valor, puede ser inflada artificialmente
- Opción B — Usuarios activos mensuales (MAU)
  · Ventajas: Métrica estándar del industry
  · Desventajas: No mide calidad del uso, solo frecuencia
- Opción C — Lugares consultados por turista
  · Ventajas: Mide valor directo, correlaciona con satisfacción
  · Desventajas: Requiere definir "turista activo"
- Opción D — Ingresos
  · Ventajas: Métrica de negocio directa
  · Desventajas: En MVP no hay ingresos, métrica retardada

**Decisión:**
Opción C — Lugares consultados por turista:
- Mide directamente el valor que la app entrega al usuario
- Si un turista consulta 3+ lugares, la app le está siendo útil
- Correlaciona con retención y satisfacción
- Es accionable: se puede mejorar con mejor contenido, mejor UX, mejor búsqueda

**Consecuencias:**
- Positivas: Claridad en decisiones de producto
- Negativas: Requiere tracking robusto
- Deuda técnica: Ninguna

**Revisión:** Revisar después de 6 meses. Evaluar si la métrica sigue siendo relevante.
