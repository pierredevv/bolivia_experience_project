## Análisis Detallado de Competidores

### 1. Google Maps / Google Local

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Plataforma general de mapas y negocios locales |
| **Alcance** | Global |
| **Fortalezas** | Base de usuarios masiva, datos precisos de ubicación, integración nativa en Android, Street View, navegación GPS |
| **Debilidades** | Contenido turístico genérico, poca curaduría local, sin eventos en tiempo real, sin información cultural profunda, sin modo offline efectivo |
| **Monetización** | Google Ads (negocios pagan por visibilidad) |
| **Cuota de mercado Bolivia** | ~70% (uso general) |
| **Amenaza para BoliviaExperience** | ALTA — Es el competidor principal por uso general |
| **Oportunidad** | Google Maps no tiene contenido curado turístico de Santa Cruz, ni eventos, ni vida nocturna detallada |

### 2. TripAdvisor

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Plataforma de reseñas y recomendaciones turísticas |
| **Alcance** | Global |
| **Fortalezas** | Base masiva de reseñas, rankings populares, integración con reservas, reputación consolidada |
| **Debilidades** | Contenido global genérico, poca presencia en Bolivia, información desactualizada en mercados emergentes, UX pesada |
| **Monetización** | Publicidad, comisiones por reservas |
| **Cuota de mercado Bolivia** | ~15% (turistas internacionales) |
| **Amenaza para BoliviaExperience** | MEDIA — Relevante para turistas internacionales pero débil en contenido local |
| **Oportunidad** | TripAdvisor tiene poca presencia en Santa Cruz; oportunidad de ser la fuente local definitiva |

### 3. Booking.com / Expedia

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Plataforma de reservas de hoteles |
| **Alcance** | Global |
| **Fortalezas** | Inventario masivo, sistema de reservas robusto, confianza del usuario, opciones de pago flexibles |
| **Debilidades** | Solo hoteles (no restaurantes, turismo, eventos), comisiones altas para negocios, sin contenido cultural |
| **Monetización** | Comisiones por reserva (15-25%) |
| **Cuota de mercado Bolivia** | ~40% (reservas de hoteles) |
| **Amenaza para BoliviaExperience** | BAJA — No compiten directamente (son solo reservas) |
| **Oportunidad** | Posible integración futura o partnership |

### 4. Yelp / Foursquare

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Directorio de negocios locales con reseñas |
| **Alcance** | Global (Yelp: USA/Europa; Foursquare: global pero débil) |
| **Fortalezas** | Comunidad activa de reseñas, gamificación (Foursquare), datos de localización |
| **Debilidades** | Presencia mínima en Bolivia, contenido escaso, UX obsoleta (Foursquare), sin eventos |
| **Monetización** | Publicidad |
| **Cuota de mercado Bolivia** | <5% |
| **Amenaza para BoliviaExperience** | BAJA — Casi inexistentes en el mercado boliviano |
| **Oportunidad** | Capturar usuarios descontentos con plataformas genéricas |

### 5. VisitBolivia / Apps Locales (si existen)

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Apps turísticas bolivianas (existentes o históricas) |
| **Alcance** | Nacional o regional |
| **Fortalezas** | Conocimiento local, contenido en español |
| **Debilidades** | Desarrollo discontinuo, UX pobre, sin mantenimiento, pocas descargas, sin actualizaciones |
| **Monetización** | Desconocida o inexistente |
| **Cuota de mercado Bolivia** | <5% (si existen activas) |
| **Amenaza para BoliviaExperience** | BAJA — No hay competidor local fuerte |
| **Oportunidad** | Absorber usuarios de apps obsoletas, establecer estándar local |

### 6. Instagram / TikTok (como descubrimiento)

| Aspecto | Detalle |
|---------|---------|
| **Tipo** | Redes sociales (descubrimiento de lugares vía contenido visual) |
| **Alcance** | Global |
| **Fortalezas** | Contenido visual atractivo, algoritmo de descubrimiento, viralidad, hashtags geolocalizados |
| **Debilidades** | No son apps turísticas, sin mapa, sin información estructurada, sin filtros de búsqueda, contenido no verificado |
| **Monetización** | Publicidad |
| **Cuota de mercado Bolivia** | Alta (uso general, no turístico específico) |
| **Amenaza para BoliviaExperience** | MEDIA — Muchos turistas descubren lugares en Instagram |
| **Oportunidad** | Integrar compartir a Instagram, usar Instagram como canal de adquisición |

## ADR-005: Estrategia de Posicionamiento vs Competidores

**Fecha:** 2026-06-26
**Estado:** Aceptado

**Contexto:**
BoliviaExperience compite con gigantes globales (Google, TripAdvisor) pero en un nicho local específico. No puede competir por volumen de usuarios ni presupuesto de marketing.

**Opciones consideradas:**
- Opción A — Competir directamente con Google Maps
  · Ventajas: Mercado grande
  · Desventajas: Imposible, recursos insuficientes
- Opción B — Nicho local diferenciado
  · Ventajas: Dominio de un segmento específico
  · Desventajas: Mercado limitado inicialmente
- Opción C — Plataforma complementaria
  · Ventajas: No compite sino complementa
  · Desventajas: Difícil de monetizar

**Decisión:**
Opción B — Nicho local diferenciado:
- Posicionar como "LA app de Santa Cruz" (no "una app turística más")
- Contenido que Google/TripAdvisor no tienen: eventos en tiempo real, vida nocturna detallada, servicios de utilidad pública, cultura local
- Experiencia offline-first para zonas sin cobertura
- Integración con ecosistema local (WhatsApp, QR BCB)

**Consecuencias:**
- Positivas: Diferenciación clara, menor competencia directa
- Negativas: Mercado limitado a Santa Cruz inicialmente
- Deuda técnica: Ninguna

**Revisión:** Revisar después de 6 meses. Evaluar expansión a otras ciudades.
