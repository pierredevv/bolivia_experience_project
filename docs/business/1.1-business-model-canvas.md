## ADR-001: Presupuesto del MVP vs Alcance Definido

**Fecha:** 2026-06-26
**Estado:** Aceptado

**Contexto:**
El prompt maestro define un presupuesto estimado de USD 20.000-30.000 para el MVP, con un equipo de 8 personas y un alcance que incluye 3 plataformas (app móvil, panel admin, panel empresa). El alcance funcional定义ido es significativamente mayor que un MVP típico de Lean Startup.

**Opciones consideradas:**
- Opción A — Reducir el alcance al MVP real
  · Ventajas: Dentro del presupuesto, foco en hipótesis críticas
  · Desventajas: No cubre todas las funcionalidades documentadas
- Opción B — Mantener alcance, incrementar presupuesto
  · Ventajas: Producto completo según especificación
  · Desventajas: Inversión inicial mayor, mayor riesgo
- Opción C — Fasear el desarrollo en 2 fases
  · Ventajas: MVP realista + complemento posterior
  · Desventajas: Complejidad de gestión, posible fragmentación

**Decisión:**
Opción C — Fasear el desarrollo. El MVP real (Fase 1) se enfoca en:
- App móvil (core): Home, mapa, categorías, fichas, favoritos, búsqueda
- Backend API: Endpoints esenciales
- Panel admin básico: Gestión de lugares y usuarios
- Panel empresa: Versión simplificada

El panel admin completo, panel empresa completo y funcionalidades secundarias se mueven a Fase 1.5 (post-MVP, antes de validación).

**Consecuencias:**
- Positivas: MVP lanza en 2-3 meses con presupuesto realista ($20,000-30,000)
- Negativas: Algunas funcionalidades se retrasan
- Deuda técnica: Posible refactorización al integrar componentes post-MVP

**Revisión:** Revisar después del launch del MVP y primeros datos de uso.

## ADR-002: Modelo de Monetización Principal

**Fecha:** 2026-06-26
**Estado:** En revisión

**Contexto:**
Definir la fuente principal de ingresos para el MVP. El mercado boliviano tiene baja penetración de tarjetas de crédito y preferencia por efectivo/QR.

**Opciones consideradas:**
- Opción A — Suscripciones a negocios (SaaS)
  · Ventajas: Ingresos recurrentes predecibles, bajo costo de transacción
  · Desventajas: Requiere masa crítica de negocios, valor demostrable
- Opción B — Publicidad nativa
  · Ventajas: No requiere pago directo del negocio, escalable
  · Desventajas: Requiere tráfico alto, experiencia de usuario puede degradarse
- Opción C — Freemium para usuarios + premium para negocios
  · Ventajas: Adquisición masiva + monetización B2B
  · Desventajas: Complejidad de gestión, dos modelos de negocio

**Decisión:**
Opción C — Modelo híbrido freemium:
- **Usuarios:** App gratuita con publicidad no intrusiva (máx 1 banner por sesión)
- **Negocios:** Plan gratuito (listing básico) + Plan premium ($29-99/mes)
  - Premium incluye: posición destacada, estadísticas, responder reseñas, promociones

**Consecuencias:**
- Positivas: Adquisición sin barrera + monetización B2B viable
- Negativas: Necesidad de demostrar valor a negocios para conversión
- Deuda técnica: Sistema de banners y planes requiere infraestructura

**Revisión:** Validar con primeros 50 negocios. Ajustar precios según feedback.

## ADR-003: Segmento de Cliente Prioritario

**Fecha:** 2026-06-26
**Estado:** Aceptado

**Contexto:**
El mercado objetivo incluye múltiples segmentos. Para el MVP, debemos priorizar para optimizar recursos de adquisición.

**Opciones consideradas:**
- Opción A — Turistas internacionales
  · Ventajas: Mayor gasto promedio, familiaridad con apps
  · Desventajas: Requiere inglés perfecto, menor volumen en Santa Cruz
- Opción B — Turistas nacionales
  · Ventajas: Mayor volumen, español nativo, menor costo adquisición
  · Desventajas: Menor gasto promedio, expectativas diferentes
- Opción C — Viajeros de negocios
  · Ventajas: Alto gasto, recurrentes, decisiones rápidas
  · Desventajas: Muy específico, bajo volumen

**Decisión:**
Opción B — Turistas nacionales como segmento primario para MVP:
- 80% del esfuerzo de marketing se enfoca en turistas nacionales
- 20% en turistas internacionales (presencia en aeropuerto, hostales)
- Razón: Mayor volumen, menor costo de adquisición, validación más rápida

**Consecuencias:**
- Positivas: Adquisición más rápida y económica
- Negativas: Ingresos potencialmente menores por turista
- Deuda técnica: Ninguna

**Revisión:** Revisar después de 1000 usuarios activos. Evaluar conversión por segmento.
