# Auditoría de Arquitectura y Layouts Frontend
**Fecha de Auditoría:** 2026-07-18
**Contexto:** Rama `design/admin-ui`
**Responsable:** Agente Arquitecto / Contexto Agéntico

## 1. Estado Actual de Layouts (React + Vite)
- **Panel Administrativo (`/admin-panel`):** Se ha migrado exitosamente la estructura base hacia un modelo de Layout asíncrono usando `React.lazy` y `Suspense`. El contenedor principal utiliza CSS Grid nativo combinado con las utilidades de Tailwind CSS para separar el `Sidebar` de navegación (fijo) del `MainContent` (scrollable).
- **Dashboard de Empresas:** Los componentes de visualización de métricas (vistas, clics, conversiones) están utilizando skeletons durante la carga de datos de la API. Se requiere optimizar el re-renderizado en las tablas de datos pesadas mediante `React.memo` o `useMemo`.

## 2. Auditoría de UI/UX y Performance
- **Lazy Loading:** Implementado en rutas pesadas, pero la división de chunks en Vite (`vite.config.ts`) necesita refinamiento para evitar que el vendor bundle (React, Firebase Auth, Tailwind) supere los 500KB.
- **Tailwind Config:** Se auditó `tailwind.config.js`. Los colores corporativos (variables de theme) están correctamente enlazados, pero hay clases arbitrarias (ej. `w-[325px]`) esparcidas en componentes menores que deben moverse a las configuraciones de la temática.

## 3. Resoluciones Aprobadas
- Queda estrictamente prohibido el uso de estilos inline. Toda personalización que escape al sistema de diseño debe añadirse vía `@apply` en capas de componentes o extenderse en Tailwind.
- Se aprueba la transición a componentes de "Bento Grid" para el Dashboard principal de administrador.
