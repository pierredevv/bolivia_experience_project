# Plan: Conectar Web Frontend al API Backend — BoliviaExperience

## Resumen

Conectar las 14 páginas del panel admin/empresa al API NestJS reemplazando datos mock por llamadas reales. Incluye: auth real, route guards, React Query hooks, formularios, y gestión de endpoints faltantes en el backend.

---

## Descubrimiento Crítico: Endpoints Faltantes en el API

El `web/src/services/api.ts` define llamadas que **no existen** en el backend:

| Web service call | Endpoint en `api.ts` | Existe en API? |
|---|---|---|
| `usersApi.getAll()` | `GET /admin/users` | **NO** — solo `/users/me` y `/users/:id` |
| `reviewsApi.getAll()` | `GET /admin/reviews` | **NO** — solo `GET /places/:id/reviews` |
| `dashboardApi.getStats()` | `GET /admin/dashboard` | **NO** |
| `dashboardApi.getEmpresaStats()` | `GET /empresa/dashboard` | **NO** |
| `empresaApi.getPlace()` | `GET /empresa/place` | **NO** |
| `empresaApi.getReviews()` | `GET /empresa/reviews` | **NO** |
| `empresaApi.getStats()` | `GET /empresa/analytics` | **NO** |

**Decisión**: Crear estos endpoints en el API como parte del plan.

## Patrón de Cada Página (Template)

Cada página sigue el mismo patrón de refactorización:

```typescript
// ANTES (mock data):
const data = [ { id: '1', name: 'Mock Item' }, ... ]

// DESPUÉS (React Query):
import { usePlaces } from '@/hooks/usePlaces'

export default function PlacesPage() {
  const [page, setPage] = useState(1)
  const [search, setSearch] = useState('')
  const { data, isLoading, error } = usePlaces({ page, limit: 12, search })

  if (isLoading) return <PlacesSkeleton />
  if (error) return <ErrorState onRetry={() => refetch()} />

  return (
    <div>
      {/* Data real de data.data (array) con data.meta (paginación) */}
      {data.data.map(place => <PlaceCard key={place.id} place={place} />)}
      <Pagination meta={data.meta} onPageChange={setPage} />
    </div>
  )
}
```
