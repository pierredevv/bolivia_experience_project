## FASE 1: Testing Backend (Prioridad MÁXIMA)

**Por qué:** El backend tiene 0 tests y es donde viven las correcciones de seguridad más críticas. Sin tests, cada cambio futuro corre riesgo de regresión silenciosa.

### 1.1 Tests Unitarios de Servicios Críticos

**Archivos a crear:**
- `api/src/modules/auth/auth.service.spec.ts`
- `api/src/modules/auth/auth.controller.spec.ts`
- `api/src/modules/places/repositories/geo.repository.spec.ts`
- `api/src/modules/reviews/reviews.service.spec.ts`
- `api/src/modules/map/map.service.spec.ts`

**Casos de prueba prioritarios:**
1. **Auth:** refresh token rechaza tokens con `type !== 'refresh'`
2. **Auth:** refresh token con JWT_REFRESH_SECRET incorrecto falla
3. **GeoRepository:** parámetros con comillas simples no rompen queries
4. **Reviews:** empresa no puede responder reseñas de otros lugares
5. **Reviews:** admin puede responder cualquier reseña

**Dependencias:** Ninguna
**Criterio de aceptación:** Jest ejecuta tests, todos pasan

### 1.2 Tests de Integración (E2E)

**Archivos a crear:**
- `api/test/app.e2e-spec.ts`
- `api/test/auth.e2e-spec.ts`
- `api/test/map.e2e-spec.ts`

**Casos de prueba:**
1. Flujo completo: register → login → refresh → access endpoint protegido
2. SQL injection: `GET /map/nearby?lat=1&lng=1&categoryId='` retorna error de validación, no 500
3. Autorización: sin token → 401; con refresh token → 401; con access token → 200

**Dependencias:** 1.1
**Criterio de aceptación:** Tests E2E pasan con `npm run test:e2e`

## FASE 3: DevOps (Prioridad ALTA)

**Por qué:** Sin Docker ni CI/CD, no hay forma reproducible de desplegar ni de validar cambios automáticamente.

### 3.1 Docker

**Archivos a crear:**
- `Dockerfile` (raíz, multi-stage build)
- `docker-compose.yml` (raíz, actualizar el existente)
- `api/Dockerfile`
- `web/Dockerfile`

**Estructura docker-compose.yml:**
```yaml
services:
  postgres:
    image: postgis/postgis:15-3.4
    # ... (ya existe)
  
  api:
    build: ./api
    ports: ["3000:3000"]
    depends_on: [postgres]
    environment:
      DATABASE_URL: postgresql://postgres:postgres@postgres:5432/bolivia_experience
  
  web:
    build: ./web
    ports: ["5173:80"]
    depends_on: [api]
```

**Dependencias:** Ninguna
**Criterio de aceptación:** `docker compose up` levanta todo el stack

### 3.2 CI/CD con GitHub Actions

**Archivos a crear:**
