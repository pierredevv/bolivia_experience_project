# Plan: Fix Errores de Compilacion en Businesses.tsx

## El Error

`Businesses.tsx` usa props incorrectas en `ConfirmDialog`:
- `confirmText` → deberia ser `confirmLabel`
- `cancelText` → deberia ser `cancelLabel`
- `onCancel` → deberia ser `onClose`
- `isDestructive` → deberia ser `variant="danger"`

## Fix

**Archivo:** `web/src/pages/admin/Businesses.tsx`

Cambiar las llamadas a `ConfirmDialog`:

```tsx
// Antes (incorrecto)
<ConfirmDialog
  confirmText="Sí, aprobar"
  cancelText="Cancelar"
  onCancel={() => setConfirmApproveId(null)}
  isDestructive
/>

// Despues (correcto)
<ConfirmDialog
  confirmLabel="Sí, aprobar"
  cancelLabel="Cancelar"
  onClose={() => setConfirmApproveId(null)}
  variant="danger"
/>
```
